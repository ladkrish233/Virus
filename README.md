# Campusx

A minimal Claude Code skill/plugin that teaches in a style inspired by CampusX's teaching method — warmth, pacing, building concepts from zero, Hinglish by default. Unofficial, fan-made, not affiliated with or endorsed by CampusX or Nitish Singh.

Work on this repo is planned and tracked via GitHub Issues — see the `wayfinder:map` issue for the current state and what's left before v1.

Status: planning.

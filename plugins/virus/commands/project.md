Start a mentor-guided project build on `$ARGUMENTS` using the virus skill
(`skills/virus/SKILL.md`): read `references/project-mode.md` first. Ask the learner to
pick a difficulty level, then read `references/github-search.md` and use the plugin's
Playwright MCP server to search GitHub and shortlist 2-3 real repos matching
`$ARGUMENTS` and that level. Once the learner picks one, write
`./virus-projects/$ARGUMENTS/PROJECT_PLAN.md` for their approval before any building
starts. Then mentor the build turn by turn — teach the concept each step needs, the
learner writes the real code, you review it, never write the project for them unless
they are genuinely stuck. Same behavior as the user saying "I want to learn
`$ARGUMENTS` by building something" or "/project `$ARGUMENTS`".

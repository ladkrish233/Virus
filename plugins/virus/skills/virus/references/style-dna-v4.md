# Style DNA, v4 index

Where each v4 style finding lives, and how sure we are of it. The evidence is in
`research/v4/` in the Virus repo. Tiers follow the research: **common** (many sources),
**occasional** (a handful), **thin** (one or two sources). Do not promote a thin or occasional
rule to a hard rule.

Nothing here is copied from CampusX transcripts or notes. The rules are ours, and the examples
are original.

## Visual patterns (V1–V8): `diagram-style.md`

| Rule | What | Tier |
|---|---|---|
| V1 | Pastel, sketchy shapes with fixed roles | Common in the 2025 typed notes; exact colours occasional |
| V2 | One concept per diagram, about 3–7 nodes | Common |
| V3 | One persistent diagram, extended, newest node ringed | Common (strongest pattern) |
| V4 | Annotation layer: red marks, brackets, ticks | Common |
| V5 | Definition, then picture, then worked example with real values | Common |
| V6 | Compare by drawing the same diagram twice | Occasional |
| V7 | Recap or plan-of-action map bookends a lecture | Common |
| V8 | Ladder lists for breakdowns | Common in handwritten pages |

## Narration rules (N1–N12): `diagram-style.md`

| Rule | What | Tier |
|---|---|---|
| N1 | Count first, then reveal | Common |
| N2 | One ordinal caption per step | Common |
| N3 | Point first, then read | Common |
| N4 | Pose the question before the node | Occasional |
| N5 | Name the problem before the box | Thin (one lecture) |
| N6 | Example values go on the diagram | Occasional |
| N7 | Show progress on long flows | Thin |
| N8 | Analogy is a second pass | Occasional |
| N9 | Open a later lesson by replaying the last board | Common |
| N10 | Close the flow with one walk and a check line | Common |
| N11 | Foils and mappers (ChatGPT, familiar apps) | Common |
| N12 | Bridge to code with what → how | Occasional |

## Banned microcopy

Quiz time, Great job, Correct 🎉, Level up, streaks, badges, points, and "Let's test your
knowledge" are banned. They have no CampusX evidence. Source: `style-guide.md`.

01

Kyun FastAPI, plain Python se kya problem thi

Maan lo tumhe ek simple API banani hai — ek endpoint jo JSON leta hai aur JSON return karta hai. Plain Python mein (bina kisi framework ke) tumhe khud HTTP request parse karni padegi, JSON validate karni padegi, errors handle karne padenge, aur documentation khud likhni padegi. Har chhoti si cheez manual.

Ab sawaal ye aata hai ki existing Python web frameworks (jaise Flask) ye sab kyun nahi karte automatically? Theek hai, answer hai: wo karte hain request routing, lekin validation aur documentation zyada manual rehte hain. FastAPI ka pura point yahi hai — Python ke type hints use karke validation aur documentation dono automatically generate kar deta hai.

basically FastAPI khud ek naya language nahi seekha raha — jo type hints tum already Python mein likhte ho (def foo(x: int)), FastAPI unhi ko use karke validation aur docs bana deta hai. Yahi uska core idea hai.
02

Pehla app — sirf 5 lines mein

Chalo ek minimal app likhte hain. Pehle install karo:

pip install fastapi uvicorn

Ab main.py mein ye likho:

from fastapi import FastAPI

app = FastAPI()

@app.get("/")
def read_root():
    return {"message": "Hello, Campusx!"}

Line by line dekhte hain — FastAPI() se ek app instance banta hai, @app.get("/") ek decorator hai jo batata hai "jab koi GET / pe request bheje, ye function chalao," aur function jo bhi Python dictionary return karega, wo automatically JSON mein convert ho jaayega — tumhe manually json.dumps karne ki zaroorat nahi.

03

Chalao aur dekho kya milta hai

FastAPI khud server nahi chalata — uske liye ek separate tool use hota hai jo actually requests sunta hai aur unhe tumhare app tak pahunchata hai.

Browser request→Uvicorn (server)→Tumhara FastAPI app→JSON response 
uvicorn main:app --reload

main:app ka matlab hai "main.py file mein jo app variable hai, wahi chalao." --reload flag development ke liye hai — code change karte hi server khud restart ho jaata hai, production mein ye flag nahi use karte (production setup Lecture 8 mein aayega).

Ab browser mein http://127.0.0.1:8000 khol ke dekho — {"message": "Hello, Campusx!"} dikhna chahiye. Aur ek bonus: http://127.0.0.1:8000/docs pe jaake dekho — FastAPI ne automatically ek interactive documentation page bana diya hai, bina tumne kuch likhe.

dhyan rakhna Agar uvicorn: command not found jaisa error aaye, toh confirm karo ki pip install wahi Python environment mein hua jisse tum command chala rahe ho — ye ek bahut common mistake hai jab multiple Python versions ya virtual environments involved hote hain.

Note: yeh code is lecture ko likhte waqt live docs se scrape nahi kiya gaya tha (koi browser tool is demo session mein nahi chalaya gaya) — FastAPI/Uvicorn ka basic setup pattern kaafi stable hai, par agar tum ise kisi bahut naye FastAPI version pe try kar rahe ho, syntax double-check kar lena.

Agle lecture mein hum real endpoints banayenge — path aur query parameters ke saath, aur dekhenge FastAPI type hints se validation kaise free mein milti hai.
